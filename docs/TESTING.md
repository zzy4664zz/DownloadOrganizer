# 验证说明

## 自动测试

核心测试使用临时文件夹中的真实文件，检查分类、预览零写入、目标重名、预览后源文件变化、整理与撤销、校验值变化、撤销冲突、部分失败、损坏记录、路径穿越、链接及中断恢复。

桌面集成测试使用真实 Tk 窗口和后台任务，只替换确认对话框的人工点击，实际执行预览、移动、关闭/重建窗口、从磁盘加载记录并撤销。还验证空目录、错误提示、取消确认和撤销冲突。测试不会触碰真实下载文件夹。

```powershell
python -m unittest discover -s tests -v
python main.py --smoke-test
```

Windows 专有的 Downloads Known Folder API、文件 rename 语义、批处理脚本和打包程序由 Windows CI 验证。无权限创建符号链接时，相应测试会报告跳过；POSIX 硬链接中断恢复测试在 Windows 上不适用。

Linux 全流程验证需要显示服务，例如：

```bash
xvfb-run -a python3 -m unittest discover -s tests -v
xvfb-run -a python3 main.py --smoke-test
```

没有显示时桌面测试会明确跳过；这种运行不能视为 GUI 验证完成。

## Windows 使用前手工检查

1. 在临时文件夹放入图片、文档、压缩包和一个子文件夹。
2. 预览后确认文件仍在原处，子文件夹不在移动清单中。
3. 整理后检查原始内容、分类位置及编号后的重名文件。
4. 关闭并重新打开程序，撤销后检查内容完整。
5. 整理后在原位置新建同名文件，撤销应报告冲突并保持两个文件。
6. 在 Windows 125% / 150% 缩放下检查布局；大文件整理期间窗口应保持响应。

## 本次验证记录

本地云环境：Linux、Xorg dummy 虚拟显示。首轮 Python 3.12.14 / Tk 9.0 完整运行 24 项测试通过。独立审查后新增回归测试，Python 3.13.5 / Tk 8.6 完整运行 31 项测试通过（零跳过）；实际窗口启动检查通过，并检查中文界面截图。

云环境自带 Tk 9.0 缺少可用的中文字形渲染支持，因此可视检查改用系统自带的 Tk 8.6，与 Windows 3.12 的常见 Tk 版本一致。桌面测试的重复窗口销毁最初暴露了测试进程内 Tk 回收线程问题，现由创建窗口的主线程回收，同时界面在完成事件后等待工作线程退出再允许关闭。

审查发现并通过失败→修复→通过的测试验证：旧窗口不能清除其他窗口的较新撤销记录；相同大小且恢复修改时间的源文件内容变化仍会跳过；中断撤销后分类空目录被删除仍可恢复；默认窗口底部日志完整显示。
