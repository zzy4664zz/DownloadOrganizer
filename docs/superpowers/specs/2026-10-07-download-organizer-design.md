# 下载整理助手设计

为 Windows 用户提供中文桌面工具：选择下载文件夹、预览分类、确认整理、撤销最近一次整理。

使用 Python 3.12+ 和标准库 tkinter；运行不需要第三方依赖。核心文件操作与界面分离。仅处理选择文件夹的直接子文件，跳过目录、符号链接、Windows 重解析点、隐藏文件和下载临时文件。类别为图片、文档、视频、音频、压缩包、安装包、其他。

预览不移动或创建文件。执行时复核文件状态，目标已存在则编号，绝不覆盖。分类目录不能是链接。操作前持久化记录，操作后更新记录；遇到错误保留已完成操作和错误说明。撤销记录保存在用户应用数据目录，重启后仍可读取；通过 SHA-256 验证内容，拒绝覆盖原路径新增文件，保留未解决记录以便重试。多个实例共享锁，避免互相覆盖记录。

界面采用单窗口：文件夹选择、分类清单、统计、预览、整理、撤销、进度和结果摘要。耗时操作在后台线程执行，控件更新由主线程处理。检测 Windows 下载目录，失败时回退到用户目录下的 Downloads。文件操作期间禁止退出，避免中断；意外结束后的未完成记录可由撤销恢复。

交付源码、Windows 启动脚本、中文使用说明、测试、GitHub Actions。标签发布触发 Windows 测试及 PyInstaller 打包，上传 exe 和源码压缩包到 GitHub Release；构建结果须独立确认。当前 Linux 环境可验证核心和虚拟显示界面，Windows 专有路径及 exe 由 Windows CI 验证。

用户已批准功能设计，并明确授权不再逐项询问、完成后发布到 GitHub。
